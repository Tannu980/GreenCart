# Problem Statement

Many small businesses and customers need a simple way to manage products, shopping carts, orders, and stock. Managing these activities manually can be difficult and may lead to errors.

The aim of this project is to develop a simple e-commerce system using Python that can manage products, users, carts, orders, and stock.

# Our Solution

GreenCart is a Python based e-commerce application that provides a simple solution for managing online shopping activities.

Customers can create an account, log in, view and search products, filter products by category, add products to their cart, place orders, and check their order history.

An admin can manage products, update stock, view users, remove products, and check low stock items.

The application uses JSON files to store data, so no external database is required.

The project demonstrates Python concepts such as Object Oriented Programming, classes, inheritance, functions, file handling, JSON, exception handling, and basic authentication.
