# GreenCart

GreenCart is a simple Python based e-commerce application. It allows users to browse products, search for items, add products to a cart, place orders, and view order history.

The project also includes an admin section for managing products, users, and stock.

## Features

1. Customer

* Register and login
* View products
* Search products
* Filter products by category
* Add and manage cart items
* Place orders
* View order history

2. Admin

* Add products
* Update products
* Delete products
* Manage stock
* View users
* Check low stock products
* View product reports

## Technologies Used

* Python
* JSON
* Object Oriented Programming
* SHA 256 password hashing

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Tannu980/GreenCart.git
```

2. Open the project folder:

```bash
cd GreenCart
```

3. Run the program:

```bash
python main.py
```

Python 3.8 or later is recommended.
